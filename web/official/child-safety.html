兒童安全政策

公布與生效日期：2026-11-19

本政策適用於「CosCircle｜同坑認親・場次預定」（Cos小圈圈）及其 Web 服務，由 CosCircle 營運團隊執行。CosCircle 是同好交流與場次預定服務，對兒童及少年性虐待及剝削採取零容忍立場。本政策中的兒少指未滿 18 歲者。

禁止行為如何檢舉處理與通報安全聯絡窗口

1. 明確禁止兒少性虐待與剝削（CSAE）

不得利用本服務製作、上傳、展示、索取、持有以供散布、交換、宣傳或散布兒少性虐待內容（CSAM），亦不得提供取得這類內容的連結或引導。禁止涉及兒少的性化描繪、性剝削影像，以及以合成、修改或其他方式製作的相關違法內容。

禁止對兒少性騷擾、性誘騙（grooming）、索取私密影像、性勒索、人口販運、媒介性交易，或以金錢、禮物、約拍、出角、工作機會及其他利益誘導兒少從事性行為或提供性化內容。不得藉由場次、位置分享、認親、名片、預定、小圈圈或其他互動功能從事上述行為。

上述規範適用於頭像、照片、自介、作品與角色說明、預定備註、戳友介紹、小圈圈、集合資訊、外部連結，以及服務中的其他使用者內容與行為。

2. 在 App 或 Web App 內檢舉

  1. 名片／使用者：開啟對方名片，點選「檢舉名片或使用者」。
  2. 活動預定：在活動詳情的對方預定卡片，點選「檢舉這筆預定」。
  3. 小圈圈：在所屬小圈圈的操作選單，點選「檢舉小圈圈」。
  4. 選擇「色情或不當裸露」；若屬誘騙、威脅、騷擾或其他兒少安全疑慮，可選「其他」。在補充說明註明「兒童安全」，描述帳號、活動、發生時間與具體問題，再點選「送出檢舉」。

沒有可見的檢舉對象、無法登入、已被封鎖或問題發生於其他互動功能時，請直接使用下方安全聯絡信箱。App「設定 → 意見回饋」的聯絡表單也可提出問題。這些管道由營運團隊人工處理，並非即時救援服務。

請勿為了檢舉而下載、保存、重製、轉傳或以附件寄送疑似違法兒少影像。提供本服務的帳號／內容識別資訊、連結及文字描述即可；不要提供密碼、驗證碼或不必要的兒少個資。

檢舉將交由管理員私下審核，系統不會向被檢舉者發送檢舉人的身分通知。你也可封鎖對方、停止位置分享或離開小圈圈。若兒少正面臨即時危險，請優先聯絡所在地警方或緊急服務。

3. 審核、移除與帳號處置

營運團隊收到 App 檢舉或安全聯絡後，會核對相關內容，優先處理涉及兒少性虐待、剝削及即時人身安全的事件。檢舉由管理員從待處理轉為審核中，記錄查核與處置結果後結案；不會因單次檢舉自動判定有罪或通知對方檢舉人身分。

一旦實際知悉服務內存在 CSAM，會依適用法律及本政策採取必要措施，包括移除相關預定或小圈圈、停權並阻止違規帳號繼續登入。涉及名片、照片或其他需另行清除的內容，由營運團隊執行必要的內容移除；不以單純結案取代違法內容處理。

我們不保證所有檢舉即時完成，也不宣稱具備自動影像偵測或全天候即時監看。處理時會限制存取人員與資料範圍，依隱私政策及適用法律處理必要紀錄。

4. 遵守法律與向主管機關通報

CosCircle 遵守適用的兒童安全與兒少性剝削防制法律。對確認涉及 CSAM 的事件，營運團隊會依法向有管轄權的地區主管機關通報；在台灣依案件情形向警方或地方社政主管機關通報。若依法適用其他地區或 NCMEC 的通報義務，依該義務辦理。

由兒童安全聯絡窗口負責協調通報、記錄案件識別資訊、通報時間與受理機關，依法配合調查及必要資料提供。必要紀錄依法律允許範圍安全處理，不向一般使用者公開，也不要求檢舉者轉傳違法影像。

若無法使用 App 檢舉，也可透過聯絡表單提供文字說明；兒少安全事件建議直接聯絡上述信箱。對處置有疑問，可來信提供案件識別資訊及申訴理由，請勿夾帶疑似違法影像。
