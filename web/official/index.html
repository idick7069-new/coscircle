Cosplay 活動同好工具

CosCircle 是給 Coser、攝影與同好一起跑場的小圈圈工具。

它不是公開交友牆，而是把活動預定、Cos 名片、同行小圈圈、現場集合和隱私保護放在同一個地方。你可以知道朋友今天出什麼角、在哪個活動、什麼時段方便互動，也能控制哪些資訊只給信任的人看。

CosCircle 在做什麼

讓活動前、活動中、活動後的資訊不再散落各處。

1

活動預定

收藏即將參加的場次，標記出席日期、角色、作品、同行身分與可互動時間，讓約拍和認親不用一直翻聊天紀錄。

2

Cos 名片

整理暱稱、作品坑單、常去地區、互動偏好與地雷資訊，用 QR Code 快速交換，不必在現場臨時補一堆自我介紹。

3

小圈圈管理

把熟人、同坑朋友、攝影夥伴分成可信任的小圈圈，資訊分享可以依關係收放，不需要一次公開給所有人。

現場與安全

大型活動裡最容易混亂的集合與隱私，CosCircle 也一起處理。

限時位置分享可設定 15、30、60 分鐘，到期自動失效。
可見位置與預定資訊可限制給小圈圈或活動內使用者。
封鎖遇到不舒服的人可以封鎖，降低被持續看見的風險。
隱身緊急隱身會停止位置分享，並把個人可見性收緊。

適合誰使用

不是只有 Coser，整個活動同行圈都能用。

Coser

公開今天出的角色、可互動時段與地雷，讓認親更順，也讓界線更清楚。

攝影

快速確認朋友場次、集合點與預定角色，減少現場找不到人的時間。

同行朋友

用小圈圈掌握大家的活動狀態，需要集合時才分享有限時間的位置。
