# 部署帳號安全與社群管理

本次功能包含帳號自行刪除、隱私政策、服務條款、同意紀錄及檢舉審核。尚未部署至正式環境，也未刪除任何正式帳號。

2026-10-30 更新：僅法律同意 GET/POST 與同意資料表已最小修補上線，修復新版 App 404。完整安全功能仍未部署；刪除帳號、檢舉與社群寫入限制不可視為已上線。見 [法律端點修補流程](/Users/frank/FlutterProjects/coscircle/docs/deployment/legal-endpoint-hotfix.md) 與 [實際驗證紀錄](/Users/frank/FlutterProjects/coscircle/docs/product/android-full-qa-2026-10-30.md)。

## 上線前確認

- 確認公開營運者名稱與聯絡管道。目前使用「CosCircle 營運團隊」及既有意見回饋表單，沒有公開私人信箱。
- 營運者需審閱隱私政策及服務條款。文件依現有功能撰寫，不代表已經過律師審核或保證商店審查通過。
- 確認備份的保存與輪替方式。不要對外承諾尚未設定的刪除期限。備份還原後，必須重新套用已核實的刪除請求，不能重新公開已刪除資料。
- 安排管理員持續查看檢舉佇列，及處理意見回饋表單中的刪除與申訴請求。程式不會代替人工判斷違規。

## 套用資料表

1. 先備份正式資料庫及上傳照片目錄。
2. 在維護時段以正式環境的既有管理方式套用 `backend/db/migrate_account_deletion.sql`、`backend/db/migrate_legal_consent.sql` 及 `backend/db/migrate_content_reports.sql`。
3. 部署 API、公開網站、管理後台及 App。同一版本必須一起上線。
4. API 啟動時會確認新增的資料表存在。未套用 migration 時不應將新版 API 切入服務。

本次開發與測試不執行上述正式資料庫操作。

## 公開入口

- `/privacy.html` 為隱私政策。
- `/terms.html` 為服務條款。
- `/delete-account.html` 可透過瀏覽器登入 Email 帳號後，重新驗證並刪除帳號，不需要安裝 App。
- 僅有 LINE 登入、無法登入或停權的帳號，可依刪除頁的指示透過聯絡表單提出請求。管理員必須核實身分，不能只憑暱稱或填入別人的 Email 就刪除。
- App 的條款頁可離線閱讀。登入後需明確勾選，才可進入社群功能與發布內容。

## 營運檢查

- 使用可拋棄的專用帳號驗證 Email 與 LINE 刪除，不使用管理員或真實使用者帳號。
- 確認刪除後原 token 不能使用，預定、位置、社交資料及建立的小圈圈均已移除。
- 刪除會解散該帳號建立的小圈圈。最後一位有效管理員不能刪除或移除自己的管理員身分。
- 照片清理由持久佇列處理，失敗會重試。啟動時及每十分鐘執行一次維護。
- 新上傳會記錄帳號歸屬。舊版檔案沒有上傳者紀錄，不能把「引用網址」當成擁有權，因此不會自動認領或刪除。相關檔名會進入 `account_legacy_upload_review`，後台統計會顯示「舊照待核實」。維運人員必須核對來源紀錄，確認歸屬與其他引用，再完成資料刪除請求。未引用的舊檔案也需在正式上線前盤點，不能宣稱本次已全部清除。
- 檢舉入口與封鎖各自獨立。管理員可審核、駁回、停權或移除對應內容，不能因為檢舉數量就自動處罰。
- 檢舉證據與管理備註最長保留九十天，帳號刪除時清除相關個資。紀錄的處理狀態不等同於保留證據。
- 驗證舊版 App 的發布請求會收到需要同意條款的提示，而不是跳過規範直接發布。

參考 [Google Play 帳號刪除要求](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en) 與 [UGC 管理要求](https://support.google.com/googleplay/android-developer/answer/12923286?hl=en)。上架時仍須依實際資料流填寫 Data safety。

個資告知內容另參考主管機關公布的 [個人資料保護法](https://law.pdpc.gov.tw/LawContent.aspx?id=FL010627)，營運者仍需確認適用規定及實際保存期限。
