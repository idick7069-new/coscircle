# 動態牆首版實作契約

2026-11-24。已依使用者採納的方案執行。

比較過兩種資料形狀：將預定內容複製成貼文快照，或由貼文連結活動／日期／作者並即時讀取原預定。採第二種，避免修改不同步、已取消預定仍顯示參加，以及小圈圈預定被公開快照擴散。

- 獨立 `social-feed.js` 擁有貼文、互動、通知的授權與交易。既有活動預定 API 呼叫同一模組處理分享選項，單次交易提交預定與分享設定。
- 預定貼文唯一鍵為作者＋活動＋dayIndex；取消後保留貼文及討論，卡片讀取時標示取消，重新預定後恢復。隱私沿用現行帳號預定可見性上限。
- 貼文類型 booking/general；可見範圍 public/friends/circle，指定圈圈必須是作者目前所在圈圈。公開一般貼文可標記活動與單一作品，圖片最多四張且必須為本人上傳。
- 所有讀取（牆、單篇、留言、互動、通知、圖片）共用可見性判斷；封鎖雙向、停權與測試資料隔離同樣適用。圈圈離開後不可續看原圈圈限定內容。管理員僅在專用審查入口查看檢舉證據，不在一般動態繞過封鎖。
- 列表依 ID 倒序游標分頁，篩選類型與關注／戳友、同坑、小圈圈；支援活動範圍。
- 留言及回覆、單一按讚；作者可關閉留言並刪除自己貼文下的留言，使用者可刪除自己的留言。刪除後隱藏正文，保留必要討論結構。
- 站內通知對同篇同類互動合併，點擊時再次授權；推播不夾帶私密正文。
- 新增貼文／留言檢舉及管理處理入口，沿用既有管理員身分與後台導覽。
- 底部改為動態、活動、現場、同好、我的；設定改由我的右上角進入。
- 不自動對既有使用者的預定發文；只有使用者明確勾選分享才新增。
- 作品資料採人工整理常見候選清單，只匯入名稱及搜尋別名，不抓取第三方介紹、圖片或建立定時爬蟲。正式匯入須先備份、正規化去重、可重複執行，保留既有作品 ID 與關聯。

## 完成後核對

實作沿用連結預定而非複製快照的形狀，預定與分享交易原子提交，正式 API 已實測取消與修改行為。站內通知採同篇同類合併、讀取時重新核對權限，沒有新增背景推播或第三方 ACG 爬蟲。新頁面沿用原像素主題與卡片，未重設其他視覺風格。測試與正式發布證據記錄於 social-feed.md。
