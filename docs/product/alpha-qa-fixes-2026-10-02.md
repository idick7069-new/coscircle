額外修正：公開名片提供正確使用者 id，禁止自我關注／封鎖；匿名操作先登入；資料庫取得連線失敗納入錯誤處理；空圈圈名稱回傳可讀錯誤；未配置真實回報表單時隱藏假入口。

部署後檢查發現並追加修正：

- 同人誌中心持續 403 會阻斷其他來源同步。已隔離來源失敗，公開 COSMOS／acosta 可在其他來源失敗時照常處理；抓取失敗不刪除／拒絕原同人誌中心資料。
- 403、429、Cloudflare 驗證頁不再啟動瀏覽器重試；正常頁面仍可解析公開 JSON-LD。此修正不代表同人誌中心的正式 VM 403 已解除，仍需來源提供合法可用介面或授權。
- 後端相容主版本範圍安全更新：axios 1.20.0、express 4.22.3、firebase-admin 14.5.0、mysql2 3.24.5 等；未改 package.json 的版本範圍。安裝安全檢查由 15 項（5 high）降為 0。

## 驗證

- Flutter 全部測試：161 項通過，包含 144 組版面測試；測試資料隔離於記憶體，沒有另開測試後端。
- Flutter 靜態分析、Node 語法檢查、部署腳本檢查通過；Android debug APK 建置通過，未安裝或更動連線手機。
- 首次設定測所有步驟，名片包含編輯，社交包含非空圈圈；每頁最多捲動五次。
- 額外以本機中英文字體執行 46 項 QA 測試並查看窄螢幕截圖；截圖不等同真機與所有字體／圖片資料驗收。
- 爬蟲解析與失敗隔離：9 項通過，未爬取新來源、未繞過 Cloudflare。
- SQL：在指定正式 GCP MySQL 8.0 使用 CTE 虛擬資料與 SELECT 驗證活動唯一性、日別、多人、多圈圈與封鎖，不建立測試帳號或改正式記錄。
- 正式 Web 使用 320 × 640 視窗確認登入可捲動、未完成社群入口隱藏、空欄位有驗證提示；沒有登入私人帳號或提交註冊。HTTP 的 service worker 安全來源告警仍存在，不能宣稱完整離線 Web 可用。
- 新增 `backend/scripts/alpha-query-check.js`，需帶入明確 DB 環境後執行；本地不要直接用預設連線誤認為正式驗證。

## 尚待外部條件

- HTTPS：等待已擁有且可設定 DNS 的網域；未完成前不宜擴大 Alpha 或宣稱傳輸安全已修好。
- 社群登入：LINE／Facebook 正式授權設定；密碼復原需郵件服務與發信網域，不能用未驗證身份的方式重設密碼。
- BUG 回報：需真實表單 URL，以 `BUG_REPORT_URL` 建置參數設定，不能填 Google Forms 根網址。
- Android／iOS：需要實機測通知撤銷、三種啟動路徑、照片上傳、定位權限、原生分享、鍵盤與背景恢復。手機 App 必須重新建置／更新才取得前端修正。
